# Cybersecurity Portfolio

A collection of practical cybersecurity lab write-ups documenting the investigation process, technical evidence, findings, and remediation recommendations from authorised training environments.

The goal of this portfolio is to demonstrate a repeatable security-testing approach—not simply to collect challenge flags.

## Methodology used in these reports

1. **Scope and context** — identify the authorised target and relevant constraints.
2. **Reconnaissance** — identify exposed services and the likely attack surface.
3. **Enumeration** — inspect application pages, endpoints, source code, and observable behaviour.
4. **Validation** — test a hypothesis using the least intrusive method that provides evidence.
5. **Impact analysis** — explain what the weakness exposes or makes possible, without overstating what was demonstrated.
6. **Remediation** — recommend practical controls that address the underlying cause.
7. **Evidence** — retain relevant command output, request details, and screenshots while avoiding unrelated sensitive data.

## Focus areas

- Web application security and authentication testing
- Network reconnaissance and service enumeration
- Vulnerability analysis and remediation
- Digital forensics and investigation workflows

## Responsible use

All testing documented here is limited to intentionally vulnerable training labs, systems I own, or environments for which I have explicit authorisation. The techniques and commands must not be used against systems without permission.
